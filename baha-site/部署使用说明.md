# 巴哈车队官网 - 部署使用说明

## 项目简介

合肥经济技术职业学院巴哈车队官方网站，采用 **Node.js + Express + SQLite** 技术栈，前端为原生 HTML + CSS + JavaScript，对标苹果中国官网极简设计风格。

## 一、本地运行

### 环境要求
- Node.js >= 18.0.0
- npm >= 6.0.0

### 启动步骤

```bash
# 进入项目目录
cd baha-site

# 安装依赖
npm install

# 启动服务
npm start
```

启动成功后：
- 前台访问：http://localhost:3000
- 后台访问：http://localhost:3000/admin
- 默认账号：`admin` / `admin123`

### 开发模式（自动重启）

```bash
npm run dev
```

## 二、如何上传和替换图片

### 方法一：通过管理后台上传（推荐）

1. 登录后台：访问 `/admin/login.html`，输入管理员账号密码
2. 进入「内容管理」页：选择对应页面，找到图片字段
3. 点击「上传图片」按钮，选择本地图片文件
4. 上传成功后图片 URL 自动填入，点击「保存」
5. 刷新前台页面即可看到替换后的图片

### 方法二：直接替换文件

将图片文件放到 `public/images/uploads/` 目录下，然后修改对应页面的 HTML 中的图片地址。

**图片替换位置标记说明：**
所有占位图片旁都有 HTML 注释标记，例如：
- `<!-- 此处后续上传替换图片/logo - 合肥经济技术职业学院校徽 -->`
- `<!-- 此处后续上传替换图片 - 首页 Hero 大图 -->`

用户上传 logo 和照片后，只需在后台对应位置上传新图片即可自动替换。

### 支持的图片格式
- JPG / JPEG
- PNG
- GIF
- WebP
- SVG

单张图片最大 5MB。

## 三、部署到 Render（推荐，免费方案）

[Render](https://render.com) 提供免费的 Web Service 托管，支持 Node.js 项目。

### 步骤

1. **注册 Render 账号**：访问 https://render.com ，用 GitHub 账号登录

2. **将代码推送到 GitHub**：
   ```bash
   git init
   git add .
   git commit -m "init"
   git branch -M main
   git remote add origin <你的GitHub仓库地址>
   git push -u origin main
   ```

3. **在 Render 创建 Web Service**：
   - 点击「New +」→ 「Web Service」
   - 选择你的 GitHub 仓库
   - 填写配置：
     - **Name**: `baha-racing-team`（自定义）
     - **Region**: 选新加坡或东京（离国内近）
     - **Branch**: `main`
     - **Runtime**: `Node`
     - **Build Command**: `npm install`
     - **Start Command**: `node server.js`
     - **Instance Type**: 选「Free」免费套餐

4. **配置环境变量（可选）**：
   在 Environment 中添加：
   - `SESSION_SECRET`：随便填一串随机字符串（用于 session 加密）
   - `PORT`：一般不需要，Render 会自动设置

5. **点击「Create Web Service」** 等待部署完成

6. 部署成功后访问 `https://你的项目名.onrender.com` 即可

### 注意事项
- Render 免费套餐 15 分钟无请求会休眠，首次访问可能需要等待几秒
- SQLite 数据库文件会在重新部署时重置（因为 Render 是无状态容器）
- **如果需要数据持久化**，建议使用 Render 的「Disks」功能挂载持久化磁盘，或改用 PostgreSQL

## 四、部署到 Vercel（备选方案）

> ⚠️ Vercel 是 Serverless 架构，SQLite 文件数据库在 Vercel 上无法持久化。
> 建议仅用于展示静态页面，后台管理功能建议使用 Render。

如果仍想用 Vercel 部署：

1. 全局安装 vercel CLI：`npm i -g vercel`
2. 在项目根目录运行：`vercel`
3. 按照提示配置项目
4. 部署完成后会得到一个 `*.vercel.app` 的域名

## 六、常见问题

### Q: 忘记管理员密码怎么办？
A: 删除 `database/baha.db` 文件，重启服务会自动重新初始化，密码重置为 admin123。

### Q: 上传图片失败？
A: 检查图片大小（最大 5MB）和格式（jpg/png/gif/webp/svg）。

### Q: 数据库文件在哪里？
A: 在 `database/baha.db`，是一个 SQLite 单文件数据库，可用 [DB Browser for SQLite](https://sqlitebrowser.org/) 打开查看。

### Q: 如何备份数据？
A: 直接复制 `database/baha.db` 文件即可，建议定期备份。

### Q: 怎么修改网站标题和版权信息？
A: 登录后台 → 内容管理 → 站点设置，可以修改站点名称、联系方式、版权信息等。
